Action keys, settlement mapping & bet-log paths

Supported actions: GAME_LIST, CREATE_PLAYER, BALANCE, DEPOSIT, WITHDRAW, LAUNCH, PLAYER_PULL_LOG, PULL_LOG. Disable create with "CREATE_PLAYER": { "enabled": false }. Optional actions respect "enabled": false. Use "autoSettleStaleSeconds": 120 when the session stays online after launch. BET_CALLBACK is inbound via the fixed Spring Boot callback URL.

Settlement: PLAYER_PULL_LOG for player/round APIs; PULL_LOG for provider-wide reports. Both share bet mapping fields.

Bet-log mapping: responseListPath or responseJsonStringPath, then playerIdPath, providerTxIdPath, betAmountPath, validBetAmountPath, winAmountPath, netAmountPath, settlementTimePath, sequencePath, eventTypePath, originalTxIdPath. Provider TX must be unique; rollback/void must point to the original TX.
